# 从零开始的 L2-hybrid 服务器任务

这是独立开发任务的需求包。接收端只需要一台 Linux 服务器和 Codex；不要求存在任何原项目目录、历史源码分支、模拟器、实验设计、数据集或对话记录。实现尚未开始，硬件路径尚未在目标服务器验证。

## 启动方式

将本包解压到服务器上任意选定的空白开发工作区。进入包含本文件的目录启动 Codex，然后发送：

```text
/goal 阅读当前目录的 GOAL_PROMPT.md、ACCEPTANCE.md 与 SOURCES.md，从公开正式 release 源码开始，在本服务器独立实现并验证单实例 L2-hybrid KV cache 系统，交付可复跑的真实执行、事件追踪和成本测量结果，供后续模拟器校准使用。按包内需求完成开发和验收；不要依赖其他项目的文件、命名、代码补丁或实验数据。先验证真实 CXL 数据路径，不能以串行暂存或普通 DRAM 仿真冒充平级直达。
```

文件阅读顺序：
1. [GOAL_PROMPT.md](GOAL_PROMPT.md)：可直接提交的完整任务。
2. [ACCEPTANCE.md](ACCEPTANCE.md)：从零定义的行为、测量与交付验收标准。
3. [SOURCES.md](SOURCES.md)：公开上游入口、源码获取方法和需现场核实的条件。
4. [MANIFEST.json](MANIFEST.json)：本包文件及 SHA-256。

## 已确定的需求

- 单台服务器、单 GPU、单 vLLM 实例；请求调度固定为该版本 vLLM 原生实现。
- 使用 vLLM 和 LMCache 正式 release，在上游基础上独立开发所需扩展。
- GPU HBM 下方，DRAM 与真实 CXL 内存为平级保留池；CXL→HBM 的数据不先复制到普通 DRAM 暂存区。
- 同一完整 KV 版本在 DRAM/CXL 间只有一个稳定归属；允许 HBM 副本共存。
- 先做简单可替换的放置/回收规则，不开发复杂预测策略，不要求证明性能改善。
- 本轮产物是实机参照与可供日后使用的测量数据。服务器上没有模拟器；不查找、安装、实现、运行、移植或适配模拟器，也不以模拟器对照作为验收条件。

## 首先需要现场核实

空闲 GPU、模型、实际 CXL backing、地址可注册/可复制条件、软件 ABI，以及真实数据路径。未核实的硬件能力不能作为已实现事实。若目标硬件不支持直达，记录原因并完成不依赖该能力的部分；不能自行将目标改成串行存储层级。

## 开发组织

由接收端为这个新项目选择简单、可维护的结构，没有从其他项目继承的目录或命名要求。只需让源码、配置、测试、生成器、原始结果和复跑说明容易找到；运行开始后将配置、步骤与验收状态落盘，便于续接。若使用上游源码，遵守其实际存在的仓库说明。

这个包不包含实现代码、依赖、模型、凭据、旧实验或源码补丁。公开上游可以重新获取；最小验证输入由本项目现场生成。没有其他本地文件需要恢复。
